# 소리통 (SoriTong)

![소리통 아이콘](assets/AppIcon.png)

**앱과 알림 내용에 따라 소리·읽어주기·앱 실행을 다르게 설정하는 macOS 메뉴 막대 앱입니다.**

화면을 열어보지 않아도 중요한 알림을 소리로 구분할 수 있도록 규칙을 만들 수 있습니다.

[최신 버전 다운로드](https://github.com/leesop/SoriTong/releases/latest) · [자세한 도움말](HELP.md)

## 현재 버전

**0.2.2 · 빌드 7**

- Apple Silicon Mac, macOS 13 이상에서 실행합니다. 이번 배포에는 Intel용 실행 파일이 포함되지 않습니다.
- 앱은 한국어 환경에서는 한국어, 그 외 환경에서는 영어로 표시됩니다.
- 실제 알림 감지는 앱과 macOS 버전에 따라 추가 확인이 필요할 수 있습니다.

## 주요 기능

- **앱·내용별 규칙:** 앱 이름, 알림 제목과 본문에 포함되거나 제외될 키워드를 지정합니다.
- **와일드카드:** `*`는 여러 글자, `?`는 한 글자에 대응합니다. 키워드를 AND 또는 OR로 결합할 수 있습니다.
- **미리 듣기 개선:** 집중 모드·통화 보호와 별개로 수동 재생합니다. Mac 음소거·음량 0 및 규칙 음량 0의 원인을 안내합니다. 화면을 잠그면 미리듣기도 중지합니다.
- **소리 선택:** 기본 알림음 14종과 직접 가져온 오디오 파일을 사용하고, 규칙별 음량을 설정합니다.
- **읽어주기:** 설치된 macOS 음성과 읽을 문장 템플릿을 지정합니다. 기본 음성은 앱 언어에 따라 한국어 또는 영어를 선택합니다.
- **앱 실행:** 소리 대신 지정한 앱을 실행하고 알림 내용을 실행 인자로 전달할 수 있습니다.
- **반복 제한:** 전체 규칙 공통·규칙별 연속 알림 무시 시간과 동일 내용의 중복 무시 시간을 설정합니다.
- **오디오 보호:** 집중 모드, 화면 잠금·잠자기, 마이크 사용, 수동 통화 보호 중에는 소리와 읽어주기를 멈춥니다. 앱 실행 규칙은 별도로 동작합니다.
- **화면 모드:** 시스템·라이트·다크 모드를 선택합니다.
- **규칙 관리:** 규칙의 우선순위 변경, 복제, 켜기·끄기, 테스트 및 최근 처리 결과 확인을 지원합니다.

## 설치

1. [릴리스](https://github.com/leesop/SoriTong/releases/latest)에서 `SoriTong-0.2.2-7.zip`을 다운로드하고 압축을 풉니다.
2. **SoriTong.app**을 **응용 프로그램** 폴더로 옮깁니다. 이전 버전이 실행 중이면 먼저 종료하고 교체합니다.
3. 앱을 실행하고 메뉴 막대 아이콘에서 설정을 엽니다.
4. **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 소리통을 허용합니다.
5. 앱의 **연결 및 상태**에서 **집중 모드 상태 접근 허용**을 선택하고 상태 공유를 허용합니다. 확인할 수 없는 상태에서는 자동 알림 오디오를 재생하지 않습니다.
6. 대상 앱의 알림 배너와 미리보기를 켠 뒤 규칙을 만들고 **알림 감지**를 켭니다.
7. 소리가 겹치면 원래 앱의 알림 소리를 직접 꺼주세요. 소리통은 원래 앱의 소리를 자동으로 끄지 않습니다.

## 사용 시 알아둘 점

- 통화 상태는 마이크 사용을 기준으로 추정합니다. 녹음 중에도 조용해지며, 마이크를 사용하지 않는 통화에는 **통화 중 (수동 보호)**를 사용해야 합니다.
- 집중 모드나 잠금 상태에서 macOS가 알림 카드를 숨기면 알림 자체를 감지하지 못합니다. 이 경우 앱 실행 규칙도 트리거되지 않습니다.
- 집중 모드 상태 공유를 끄거나 상태를 읽을 수 없으면 자동 알림의 소리·읽어주기를 멈춥니다. 집중 모드의 허용 앱에 소리통을 넣으면 시스템이 집중 상태를 꺼짐으로 알려줄 수 있습니다.
- 인자 전달을 사용하려면 대상 앱이 해당 실행 인자를 지원해야 합니다.
- 알림 센터 기록을 열면 과거 알림이 감지될 수 있습니다. 실제 앱별 감지 범위와 설정 방법은 [도움말](HELP.md)을 확인하세요.

## 개인정보와 저장

소리통은 서버나 메신저 계정에 연결하지 않고 규칙을 이 Mac에서 처리합니다. 최근 알림은 메모리에만 최대 60개 남으며 종료하면 사라집니다. 규칙·설정·가져온 오디오는 이 Mac에 저장합니다. 마이크 사용 여부만 확인하며 마이크 소리를 녹음하지 않습니다.

앱 실행 규칙을 설정하면 지정한 알림 내용이 선택한 앱으로 전달됩니다. 전달된 내용의 처리는 대상 앱의 설정에 따릅니다.

## 파일 무결성 확인

릴리스의 ZIP과 `SHA256SUMS.txt`를 같은 폴더에 내려받은 뒤 터미널에서 다음 명령으로 확인할 수 있습니다.

```sh
shasum -a 256 -c SHA256SUMS.txt
```
